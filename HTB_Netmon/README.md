# Scope

Netmon is an entry-level Windows machine that involves straightforward enumeration and exploitation. It runs PRTG, and an FTP service with anonymous login enabled provides access to read PRTG Network Monitor configuration files. The installed PRTG version is susceptible to remote code execution (RCE), which can be leveraged to obtain a SYSTEM-level shell.
